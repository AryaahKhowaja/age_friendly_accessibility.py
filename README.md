# Geospatial Vulnerability & Urban Planning Pipelines

An open-source portfolio of spatial analysis workflows in Python and R, focused on climate adaptation, socio-demographic vulnerability indexing, and age-friendly urban infrastructure planning.

---

## 📁 Repository Structure

```text
├── heat_vulnerability_index.R          # R spatial pipeline (sf, terra, tmap)
├── Heat Vulnerability.py / .ipynb      # Python heat vulnerability pipeline (GeoPandas, scipy)
├── age_friendly_accessibility.py       # Python walkability & senior accessibility analysis
└── outputs/
    ├── hvi_vulnerability_map.png       # Multicriteria heat risk map
    └── age_friendly_park_accessibility.png  # Park deficit priority map
